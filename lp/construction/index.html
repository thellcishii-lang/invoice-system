仕様の強み

分類も、登録数も、無制限。
送り方も3通りそろっています

品目の分類ツリーは横にも下にも無制限に展開でき、登録数にも上限を設けていません。帳票まわりの仕様としてはほぼ網羅した構成で、これ以上の作り込みが必要になるのは、自社専用にシステムを開発する場合くらいです。

分類ツリー

品目の分類は、横にも下にも無制限

分類ツリーは、横（兄弟分類の数）にも下（階層の深さ）にも無制限に展開できます。大分類・中分類・小分類…と、工事の分類体系をそのまま再現できるので、分類の多い業種にも対応できます。

建築版では、この分類（中分類）がそのまま見積書の内訳書と明細ページの構成になります。

すべて無制限

無制限なのは、帳票だけではありません

発行する帳票の数だけでなく、登録する取引先・品目・メンバーの数にも上限はありません。件数が増えても、料金は月額のまま変わりません。

  • 帳票（見積・発注・納品・請求・領収）無制限
  • 取引先（顧客）の登録数無制限
  • 品目の登録数無制限
  • メンバー（利用者）の人数無制限
送信

送り方は3通り。自動送信も装備

相手先に合わせて、紙・メール・FAX送り状から選べます。日時を指定する予約配信と、定期請求の自動送信にも対応しています。

  • 封筒 ― 長形3号・長形4号の宛名印刷（ロゴ・差出人の印字つき）
  • メール ― 公開リンク付きで送信。自社のメールアドレス（自社SMTP）から送る設定も可能で、相手が帳票を見たかどうかも分かります
  • FAX ― FAX送り状の印刷に対応しています

※ FAX回線からの送信そのものは、オプションとして準備中です。現行機能はFAX送り状の印刷までとなります。

税務まわりへの対応

請求書は、インボイス制度（適格請求書）の様式に対応しています。

  • 適格請求書発行事業者の登録番号を記載できます
  • 税率ごとに区分して記載し、税率ごとに消費税額を計算します
  • 軽減税率（8%）と標準税率（10%）が混在する帳票にも対応します

発行した帳票は、クラウドに保管

発行した帳票の控えはクラウド上に保管されるので、紙の控えをファイリングして探し回る必要がありません。

  • 取引先名・金額・日付・件名などで検索できます
  • 過去の帳票をいつでも開いて、再印刷・PDF表示ができます
  • 下書き・発行済みなどの状態や入金状況でも絞り込めます

帳票ギャラリー

5種類の帳票の印刷イメージを、全部並べました

見積書（建築様式の表紙・内訳書・明細）から、発注書・納品書・請求書・領収書まで。気になる帳票をクリックすると、大きく表示されます。内容はすべてサンプルデータです。

発注書

発注書は2系統。
しかも見積の流れのまま作れるから、使われます

発注書には「お客様から受ける発注（受注）」と「業者へ出す発注」の2系統があります。両方に対応している帳票サービスは多くありません。さらに当システムの発注書は、見積書から変換して作れます。単体で新規に作る発注書は、見積の流れから切り離されて結局使われなくなりがちですが、流れの中にある発注書は、業務の中でそのまま使えます。

系統 1 ― 受注

お客様からの発注を受ける「受注」

見積の内容を、お客様に正式に発注してもらうための書面です。見積書から変換して作るので、確認済みの明細がそのまま発注内容になります。入力し直す手間も、転記ミスもありません。

印刷では、発行者がお客様、宛先が自社になり、押印欄が付きます。「お客様が発注し、自社が受ける」という実際の取引の向きそのままの書面になります。

系統 2 ― 発注

協力業者・仕入先へ出す「発注」

工事の一部や材料を、協力業者・仕入先へ発注するための書面です。印刷では、発行者が自社、宛先が業者になり、納期や納入場所も明記できます。

受注と発注は区分で切り替わり、印刷の向き（宛先と発行元）が自動で入れ替わります。2系統を1つの帳票として扱えるので、現場の発注まわりが1か所にまとまります。

1. 見積を作る

いつも通り、見積書を作成します。建築版なら表紙・内訳書・明細の建築様式です。

2. 「この内容でいいか」を確認してもらう

見積をお客様に見せて、工事内容と金額に間違いがないか確認してもらいます。

3. その内容が、丸ごと発注書になる

ワンクリック変換で、確認済みの内容がそのまま受注の発注書になります。これが、発注書がいちばん自然に残る形です。

発注書は、「言った・言わない」を防ぐ大切な一枚です

建設業では、工事内容や金額の行き違いが、そのままもめごとに直結します。口頭の約束だけでは、あとから「そんな話は聞いていない」「金額が違う」という行き違いを防げません。発注内容を書面で残しておくことは、行き違いを防ぎ、取引先との信頼を守ることにつながります。発注書は面倒な書類ではなく、信頼を守るための大切な書面です。だからこそ、見積の流れの中で無理なく作れる形にしました。

帳票の流れ

見積から請求、入金確認まで

帳票は下書きで作って、発行する流れ。作った帳票はワンクリックで次の帳票に変換できるので、同じ内容を何度も入力し直す必要がありません。

1. 下書きで作って、発行する

見積書・発注書・納品書・請求書・領収書の5種類。まずは下書きとして保存し、内容を確認してから発行します。

2. ワンクリックで変換する

見積 → 発注 → 納品 → 請求と、帳票同士をワンクリックで変換。明細をそのまま引き継げるので、転記ミスが減ります。

3. 封筒・メール・FAX送り状で送る

封筒の宛名印刷、公開リンク付きのメール送信、FAX送り状の印刷に対応。予約配信と定期請求の自動作成・自動送信もでき、送信履歴と再送、公開リンクの閲覧確認もできます。

4. 入金を確認する

入金を記録し、未入金の一覧と月別レポートで請求後のフォローまで。入金が済んだら領収書を発行します。

できること

工事の帳票まわりに必要なものを、ひととおり

建築様式の見積印刷に加えて、品目マスターや粗利管理、送信・入金管理まで。月額料金の中に全部入っています。

建築様式の見積印刷

見積書を「表紙（工事名・施主・金額・工期など）→ 内訳書（中分類ごとの合計）→ 中分類ごとの明細」の構成で、A4横に印刷できます。

品目マスター（分類ツリーと品番）

分類ツリーは横（兄弟分類）にも下（階層）にも無制限。大分類・中分類・小分類…と工事の分類をそのまま再現でき、階層式の品番で品目を登録して、見積に呼び出せます。品目の登録数も無制限です。

粗利管理

品目ごとに原価（仕入単価）を登録でき、帳票ごとに売上・原価合計・粗利・粗利率が見えます。原価は帳票に印刷されない、社内専用の情報です。

5種類の帳票とワンクリック変換

見積書・発注書・納品書・請求書・領収書。下書きで作って発行する流れで、帳票同士はワンクリックで変換できます（見積 → 発注 → 納品 → 請求）。

発注書は2種類に対応

お客様からの「受注」と、業者への「発注」。区分によって印刷の向き（宛先と発行元）が切り替わります。見積から変換した発注書は自動で「受注」になります。

インボイス制度対応

適格請求書（インボイス制度）対応の様式で、登録番号の記載、税率ごとの区分記載、税率ごとの消費税額の計算に対応。軽減税率（8%）と標準税率（10%）の混在にも対応しています。発行した帳票の控えはクラウドに保管され、検索・再印刷・PDF表示がいつでもできます。

テンプレート

よく使う帳票はテンプレート化して再利用できます。同じ内容の帳票を、毎回ゼロから作り直す必要がありません。

送信と自動化

送り方は、封筒の宛名印刷・メール送信・FAX送り状の印刷の3通り（FAX送信はオプションで準備中）。公開リンク付きメールは相手が帳票を見たかどうかが分かり、自社のメールアドレス（自社SMTP）から送る設定も可能です。予約配信、定期請求の自動作成・自動送信、送信履歴と再送にも対応します。

入金管理

入金の記録、未入金の一覧、月別レポート。請求したあとの「まだ入っていない」を取りこぼしません。

封筒の宛名印刷

長形3号・長形4号に対応し、横向き・縦向きが選べます。ロゴと差出人の印字にも対応しています。

帳票デザインのカスタマイズ

帯の色、シマシマ（ストライプ）行、背景パターン、ロゴと印鑑の配置を、自社の帳票らしく整えられます。

メンバーは人数無制限

メンバーは招待制で、人数は無制限。各自が自分のパスワードでログインします。人数が増えても料金は変わりません。

機能一覧（詳細）

上のカードで紹介した機能を、項目ごとに細かく書き出しました。すべて月額料金に含まれます。

1帳票の作成

  • 5種類の帳票（見積書・発注書・納品書・請求書・領収書）、すべて作成無制限
  • 作成はまず下書きとして保存し、内容を確認してから「発行する」流れ
  • 見積 → 発注 → 納品 → 請求のワンクリック変換（明細をそのまま引き継ぐ）
  • 帳票の種類ごとにテンプレートを作成・保存して再利用（テンプレートから作成／帳票をテンプレートとして保存）
  • メール／FAXの送り状（カバー）テンプレートも種類ごとに用意
  • 社内だけが見られるメモ欄（帳票には印刷されません）
  • 変換元・変換先など関連する帳票の紐付け表示

2建築版の見積印刷

  • 表紙 → 内訳書 → 中分類ごとの明細の3部構成、A4横で印刷
  • 表紙には工事名・施主・見積金額・工期などを印字
  • 内訳書は中分類ごとの合計金額を一覧表示
  • 明細ページの小計は、内訳書の金額と一致
  • 分類されていない明細は「その他」の明細ページに自動で集約

3品目マスター

  • 分類ツリーは横（兄弟分類）にも下（階層）にも無制限
  • 分類ごとに3桁の番号、品目は階層式の品番で自動採番（番号の使い回しなし）
  • 分類の全体像をツリーで確認でき、分類を選ぶと配下の品目を表示
  • 品目ごとに仕入単価（原価）を登録でき、帳票の明細では行ごとに調整も可能
  • 品目の登録数は無制限

4送信・配信

  • メール送信（公開リンク付き）。相手がリンクを開いたか分かる閲覧確認
  • 自社のメールアドレスから送れる自社SMTP設定（返信先は自社に届きます）
  • 封筒の宛名印刷（長形3号・長形4号、横向き／縦向き、ロゴ・差出人の印字）

よくある質問

FAQ

Q建築版の見積書は、どんな構成で印刷されますか？

A4横で、「表紙（工事名・施主・金額・工期など）→ 内訳書（中分類ごとの合計金額）→ 中分類ごとの明細ページ」の構成です。分類されていない明細は「その他」にまとまります。

Q内訳書の「中分類」は、どこで決まりますか？

品目マスターの分類ツリーです。大分類・中分類…と階層は無制限で、品目には階層式の品番が付きます。見積の明細に選んだ品目の分類が、そのまま内訳書と明細ページの構成になります。

Q一般版と建築版の違いは何ですか？

建築版では、見積書を建築様式（表紙 → 内訳書 → 明細、A4横）で印刷できます。料金は一般版と同額で、その他の機能は同じです。申込のときに版を選びます。

Q帳票の作成数に上限はありますか？

ありません。見積書・発注書・納品書・請求書・領収書のすべてが無制限です。帳票だけでなく、取引先（顧客）の登録数、品目数、メンバー数もすべて無制限で、件数が増えても料金は変わりません。

Q発注書は「受注」と「発注」の2種類があるのですか？

はい。お客様から受ける発注（受注）と、協力業者・仕入先へ出す発注の2系統に対応しています。受注の発注書は見積書から変換して作れ、印刷では発行者がお客様・宛先が自社になり、押印欄が付きます。発注の発注書は、発行者が自社・宛先が業者になります。発注内容を書面で残すことで、「言った・言わない」の行き違いを防げます。

Q原価や粗利は、お客様に見えますか？

見えません。原価（仕入単価）・原価合計・粗利・粗利率は社内専用の情報で、印刷される帳票や公開リンクには含まれません。

Qインボイス制度に対応していますか？

はい。適格請求書（インボイス制度）対応の様式で、登録番号の記載、税率ごとの区分記載、税率ごとの消費税額の計算に対応しています。軽減税率（8%）と標準税率（10%）が混在する請求書も作れます。

Q利用人数に上限はありますか？

ありません。メンバーは人数無制限で、招待制です。招待されたメンバーは各自が自分のパスワードを設定してログインします。

Q支払い方法は？

クレジットカード払いです。月払い（税抜2,500円／税込2,750円）と年払い（税抜25,000円／税込27,500円、月払いより2ヶ月分お得）から選べます。初期費用は0円、最低利用期間はありません。

Q年払いにすると、HTMLメールが付いてくるのですか？

はい。今なら年払い（1年契約）でお申し込みいただくと、初年度はHTMLメールが無料で付いてきます。HTMLメールは単体でもご利用いただける製品で、単体価格は月額 税抜2,500円（税込2,750円）です。年払いの特典として初年度分が含まれますので、別途お申し込みや追加料金は不要です。詳しくはHTMLメールのページをご覧ください。

Q定期的な請求は自動化できますか？

はい。定期請求の自動作成・自動送信に対応しています。日時を指定する予約配信もできます。送信履歴の確認と再送も可能です。

Q封筒の宛名印刷はできますか？

はい。長形3号・長形4号に対応し、横向き・縦向きが選べます。自社のロゴと差出人の印字もできます。

QFAXで帳票を送れますか？

現行機能では、FAX送り状の印刷に対応しています。FAX回線からの送信そのものはオプションとして準備中です。送り方はこのほか、封筒の宛名印刷とメール送信に対応しています。

Q品目の分類は、どこまで細かく作れますか？

分類ツリーは、横（兄弟分類の数）にも下（階層の深さ）にも無制限です。大分類・中分類・小分類…と、自社の分類体系をそのまま再現できます。品目の登録数にも上限はありません。

Q発行した帳票は、どう保管されますか？

発行した帳票の控えはクラウド上に保管されます。取引先名・金額・日付・件名などで検索でき、過去の帳票をいつでも開いて再印刷・PDF表示ができます。

Q送った帳票を、相手が見たかどうか分かりますか？

はい。メールで送った帳票は公開リンクで届き、相手がリンクを開いたかどうか（閲覧確認）が分かります。メールは自社のメールアドレス（自社SMTP）から送る設定も可能です。
