見積・請求書システム 利用規約

第1条（適用）

  1. 本規約は、Everyone's 合同会社（以下「当社」といいます）が提供する「見積・請求書システム」（以下「本サービス」といいます）の利用条件を定めるものです。
  2. 本サービスを利用する事業者（以下「利用者」といいます）は、本規約に同意のうえ、本サービスを利用するものとします。
  3. 当社が本サービス上で随時公表する個別の定め（料金プラン、機能説明、ヘルプ等）は、本規約の一部を構成するものとします。ただし、本規約と個別の定めが矛盾する場合は、本規約が優先するものとします。

第2条（定義）

本規約において、次の用語はそれぞれ次の意味で使用します。

  1. 「本サービス」：見積書・発注書・納品書・請求書・領収書等の帳票を作成・送信・管理するためのクラウド型ソフトウェアサービス「見積・請求書システム」をいいます。一般版および建築版を含みます。
  2. 「テナント」：本サービス上に設けられる、利用者ごとの管理領域をいいます。
  3. 「利用者」：本サービスを契約し利用する事業者（法人または個人事業主）をいいます。
  4. 「メンバー」：利用者が招待し、本サービスにログインして利用する担当者をいいます。
  5. 「取引先」：利用者が本サービスに登録する、帳票の宛先となる顧客・仕入先等をいいます。
  6. 「帳票」：本サービスで作成される見積書・発注書・納品書・請求書・領収書等の文書をいいます。

第3条（利用申込と契約の成立）

  1. 本サービスの利用を希望する者は、当社の定める方法により申込を行うものとします。
  2. 当社が申込を承諾し、テナントおよび最初のログインIDを発行した時点で、本規約に基づく利用契約が成立するものとします。
  3. 当社は、申込者が過去に本規約に違反したことがある場合、その他当社が不適切と判断する場合には、申込を承諾しないことがあります。

第4条（アカウントの管理）

  1. 利用者およびメンバーは、発行されたログインIDおよびパスワードを、自己の責任において厳重に管理するものとします。
  2. ログインIDの第三者への貸与・譲渡・共有は禁止します（1ログインIDにつき利用者1名とします）。
  3. ログインIDを用いて行われた行為は、当該ログインIDの保有者による行為とみなします。
  4. 利用者およびメンバーは、ログインIDの不正使用を知った場合、直ちに当社に連絡するものとします。

第5条（料金および支払）

  1. 本サービスの料金は、初期費用0円、月払いの場合は月額2,500円（税別）、年払いの場合は年額25,000円（税別）とします。一般版・建築版とも同額です。
  2. 利用料は、クレジットカード決済（決済代行事業者：Stripe）によりお支払いいただきます。初回は利用契約の成立日に課金され、以降は月払いの場合は毎月同日に、年払いの場合は毎年同日に、自動で課金されます（前払い）。
  3. FAX送信オプション等の有料オプションを利用する場合は、別途定める料金が加算されます。（金額は申込ページ等で別途表示します）
  4. 支払われた利用料は、理由のいかんを問わず返金しないものとします。ただし、当社の責に帰すべき事由により本サービスを長期間利用できなかった場合は、この限りではありません。

第6条（契約期間・解約）

  1. 本サービスに最低利用期間はありません。
  2. 利用者は、当社の定める方法により、いつでも解約を申し出ることができます。解約の申し出があった場合、次回以降の課金は停止され、利用者は次回支払日の前日まで本サービスを利用することができます。利用契約は、当該期間の終了をもって終了します。
  3. 利用契約が終了した後は、テナント内のデータにアクセスできなくなります。当社は、契約終了後30日間当該データを保持し、その後削除します。
  4. 利用者に本規約違反がある場合、当社は催告なく利用契約を解除し、本サービスの提供を停止することができます。

第7条（本サービスの内容）

本サービスは、主として次の機能を提供します。

  1. 帳票（見積書・発注書・納品書・請求書・領収書）の作成、下書き・発行管理、帳票間の変換
  2. 取引先マスターおよび品目マスター（分類ツリー・階層式品番）の管理
  3. 帳票の送信（メール送信、予約配信、定期請求による自動作成・送信、送信履歴の管理）
  4. 入金の記録・管理、未入金の確認、月別レポート
  5. 封筒の宛名印刷、帳票デザインのカスタマイズ
  6. 原価・粗利の管理（社内向け情報として、帳票には表示されません）

なお、本サービスは帳票の作成・送信・管理を行うものであり、利用者の取引先からの代金の回収や決済の代行を行うものではありません。入金の記録は、利用者が実際の入金を確認して登録するものです。

第8条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為を行ってはなりません。

  1. 法令または公序良俗に違反する行為
  2. 当社または第三者の権利（知的財産権、プライバシー等）を侵害する行為
  3. 本サービスの運営を妨害する行為（過度な負荷をかける行為、不正アクセス等）
  4. ログインIDの不正利用、なりすまし
  5. 本サービスを当社の承諾なく第三者に再販売・再提供する行為
  6. 反社会的勢力への利益供与その他これに準ずる行為
  7. その他、当社が不適切と判断する行為

第9条（知的財産権）

  1. 本サービスおよび本サービスに関連するソフトウェア、文書、ロゴ等に関する知的財産権は、当社または正当な権利者に帰属します。
  2. 利用者が本サービスに登録したデータ（取引先情報、品目情報、帳票データ等）の権利は、当該利用者に帰属します。
  3. 利用者は、前項のデータを本サービスの提供・維持・改善の目的の範囲で当社が利用することに同意するものとします。

第10条（データの取扱い）

  1. 利用者は、本サービスに登録する取引先情報等について、適法に取得し、必要な同意を得たうえで登録するものとします。
  2. 当社は、登録されたデータを本サービスの提供目的以外に利用しません。個人情報の取扱いの詳細は、別途定めるプライバシーポリシーによるものとします。
  3. 利用者は、自己の責任においてデータのバックアップを行うものとします。
  4. 利用者が発行した帳票のデータは、利用契約の継続中、本サービス上に保管されます。税法上必要となる帳票の保存期間・保存方法の管理は、利用者自身の責任において行うものとします。

第11条（本サービスの変更・中断・終了）

  1. 当社は、本サービスの内容を、利用者に事前に通知のうえ変更することができます。ただし、緊急の場合は事後の通知によることがあります。
  2. 当社は、システムの保守、障害、天災地変その他やむを得ない事由により、本サービスの提供を一時的に中断することができます。
  3. 当社は、相当の予告期間をもって通知することにより、本サービスの全部または一部の提供を終了することができます。

第12条（免責）

  1. 当社は、本サービスが利用者の特定の目的に適合すること、期待する成果が得られることを保証するものではありません。
  2. 本サービスにより算出される金額・税額等は、利用者の設定および入力に基づく計算結果であり、その正確性について利用者自身が確認するものとします。
  3. 利用者と取引先との間の取引・紛争について、当社は関与せず、責任を負わないものとします。

第13条（責任制限）

  1. 当社が本サービスに関して利用者に対して負う損害賠償責任は、当社の故意または重大な過失による場合を除き、損害発生時点から遡って1か月間に利用者が当社に支払った利用料の額を上限とします。
  2. 当社は、間接損害、逸失利益について責任を負わないものとします。ただし、消費者契約法その他の法令により制限できない範囲についてはこの限りではありません。

第14条（料金改定）

当社は、利用料その他の料金を改定することができます。改定を行う場合は、効力発生日の相当期間前までに、利用者に通知または本サービス上で公表するものとします。

第15条（規約の変更）

当社は、必要に応じて本規約を変更することができます。変更後の規約は、本サービス上に公表した時点または当社が定める効力発生日から効力を生じるものとし、効力発生日後に本サービスを利用した利用者は、変更に同意したものとみなします。

第16条（通知）

本サービスに関する当社から利用者への通知は、登録されたメールアドレスへの送信、本サービス上の表示その他当社が適当と判断する方法により行います。

第17条（権利義務の譲渡）

利用者は、当社の事前の書面による承諾なく、本規約上の地位または権利義務を第三者に譲渡することはできません。

第18条（準拠法・管轄）

  1. 本規約の準拠法は日本法とします。
  2. 本サービスに関して紛争が生じた場合は、当社の本店所在地を管轄する地方裁判所を第一審の専属的合意管轄裁判所とします。
